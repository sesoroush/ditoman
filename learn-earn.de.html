Zehn Lektionen lesen, Test bestehen, TMN erhalten

طرح آزمایشی دیتومان برای کسانی که می‌خواهند کریپتو را درست یاد بگیرند. درس‌ها را بخوان، به آزمون ده‌سؤالی جواب بده و با دست‌کم هشت جواب درست، پاداش TMN بگیر.

Ditomans Pilotprogramm für alle, die Krypto richtig lernen wollen. Lesen Sie die Lektionen, machen Sie den Test mit zehn Fragen, und mit mindestens acht richtigen Antworten erhalten Sie eine TMN-Belohnung.

  2. آزمون ده‌سؤالیTest mit zehn Fragen
  3. کد و آدرس کیف پول را بفرستSenden Sie Ihren Code und Ihre Wallet-Adresse
رفتن به آزمونZum Test

پاداش هر نفرBelohnung pro Person

  • هر کیف پول فقط یک بار پاداش می‌گیرد.
  • Jede Wallet kann die Belohnung einmal erhalten.
  • آدرس باید کیف پول شخصی روی شبکه‌ی BNB Smart Chain باشد، نه آدرس صرافی. راهنمای اضافه کردن TMN به کیف پول
  • Nutzen Sie eine eigene Wallet auf der BNB Smart Chain, keine Börsenadresse. So fügen Sie TMN Ihrer Wallet hinzu
  • پاداش‌ها هر چند روز یک بار، دسته‌ای فرستاده می‌شوند.
  • Belohnungen werden alle paar Tage gebündelt versendet.
  • این پاداش برای یادگیری است، نه وعده‌ی سود.
  • Die Belohnung gilt dem Lernen, sie ist kein Gewinnversprechen.

قدم اول: ده درسSchritt eins: die zehn Lektionen

هر سؤال آزمون از یکی از این درس‌هاست. هر درس حدود پنج دقیقه وقت می‌گیرد.

Jede Testfrage stammt aus einer dieser Lektionen. Jede Lektion dauert etwa fünf Minuten.

    قدم دوم: آزمونSchritt zwei: der Test

    ده سؤال، از هر درس یکی. برای قبولی دست‌کم هشت جواب درست لازم است. اگر قبول نشدی، درس‌هایی را که اشتباه جواب دادی دوباره بخوان و باز امتحان کن.

    Zehn Fragen, eine aus jeder Lektion. Sie brauchen mindestens acht richtige Antworten zum Bestehen. Wenn nicht, lesen Sie die Lektionen mit falschen Antworten noch einmal und versuchen Sie es erneut.

    قدم سوم: دریافت پاداشSchritt drei: Belohnung abholen

    آدرس کیف پول BNB Smart Chain خودت را وارد کن. یک کد اختصاصی ساخته می‌شود. پیام آماده را کپی کن و برای دیتومان بفرست.

    Geben Sie Ihre BNB-Smart-Chain-Wallet-Adresse ein. Ein persönlicher Code wird erstellt. Kopieren Sie die fertige Nachricht und senden Sie sie an Ditoman.

    آدرس کیف پول را از کجا بیاورم؟Woher bekomme ich eine Wallet-Adresse?
    1. یک کیف پول شخصی نصب کنید؛ مثلاً تراست ولت یا سیف‌پل. آدرس صرافی (نوبیتکس، والکس و مانند آن) قبول نیست.
    2. کیف پول را بسازید و ۱۲ کلمه‌ی بازیابی را روی کاغذ بنویسید. آن را به هیچ‌کس ندهید.
    3. در کیف پول، شبکه‌ی BNB Smart Chain را انتخاب کنید و «دریافت» (Receive) را بزنید.
    4. آدرسی که نشان می‌دهد با 0x شروع می‌شود و ۴۲ کاراکتر دارد. آن را کپی کنید و همین‌جا جای‌گذاری کنید.
    1. Installieren Sie eine persönliche Wallet, zum Beispiel Trust Wallet oder SafePal. Eine Börsenadresse wird nicht akzeptiert.
    2. Erstellen Sie die Wallet und schreiben Sie die 12 Wiederherstellungswörter auf Papier. Geben Sie sie niemals jemandem.
    3. Wählen Sie in der Wallet das BNB Smart Chain und tippen Sie auf Empfangen.
    4. Die angezeigte Adresse beginnt mit 0x und hat 42 Zeichen. Kopieren Sie sie und fügen Sie sie hier ein.
